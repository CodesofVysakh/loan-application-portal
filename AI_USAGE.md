# AI Usage

## Tools Used

* **ChatGPT:** Used as a development assistant for implementation guidance, troubleshooting, code review suggestions, and test-writing assistance.
* **Local development tools:** Nx, NestJS, React, Prisma, MySQL, and Playwright were used to build and verify the application.

## How AI Assisted

AI assistance was used iteratively during development to:

* Review setup instructions and document known limitations.
* Troubleshoot project configuration and build issues.
* Discuss backend and frontend implementation approaches.
* Help develop API functionality and frontend components.
* Draft and refine automated smoke tests.

Suggestions were applied and adjusted to fit the project. The resulting code was built and tested locally.

## Verification

Verification included application builds, API and frontend end-to-end tests, database connectivity checks, and manual checks of customer and administrator workflows.

## Limitations and Future Improvements

The current implementation is an assessment prototype rather than a production-ready banking system. Potential improvements include durable background-job processing, more comprehensive automated tests, stronger production security controls, and integration with real banking and credit-check services.
